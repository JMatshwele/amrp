Quick Start

Before using the application, start the backend server in PowerShell:

cd C:\Users\drjam\BAMSTU_BIOINFO\backend
python server.py
# Wait for: Uvicorn running on http://127.0.0.1:8080
⚠ Important: Use python server.py — NOT python -m uvicorn main:app (the file is server.py, not main.py).
How to Run a Simulation
  1. Start the backend server (see above)
  2. Click ⚡ LAUNCH THE APPLICATION
  3. Upload your compound's .xyz coordinate file (get this from BAMSTU Quantum Chemistry Studio)
  4. Select a target pathogen from the dropdown
  5. Select Docking Exhaustiveness: 8 — fast (2–5 min)  |  16 — standard / default  |  32 — publication grade (10–20 min)
  6. Click ⚡ Simulate True Blind Docking and wait 30–90 seconds
  7. Click any protein target card to load its 3D structure
  8. Click Calculate Euclidean Bonds to see intermolecular interactions
  9. Export your results (CSV, PNG, LigPlot SVG)

Run controls — seed and replicates▾
A single Vina run is one draw from a stochastic search, not a measurement. Set replicates above 1 and the backend returns a mean and standard deviation instead of a point estimate. The seed and the replicate count both belong in the Methods section.

Target panel verification (live RCSB check)▾
Checks the deposited organism against the pathogen each entry claims, and confirms every configured active-site residue exists in the chain. A residue list that points at nothing makes the pocket centroid fall back to the whole-protein centre, so the docking targets the middle of the structure while the output still names the active site. This is what happened to PBP2a in v3.1.

Verification, validation, uncertainty▾
Redocking RMSD is the test that decides whether any other number here is worth reading. Results by docking semantics▾
Three tables, not one ranked list. A favourable score against a porin means the compound fits the channel — that is transit, not inhibition, and it points the opposite way to an inhibitor reading. Against an adhesin it means interface occlusion, which predicts no MIC shift at all. Pooling them into a single affinity ranking compares opposite mechanisms, which is what the v3.1 single table did.

Before this goes in a manuscript▾

Safe to report, with three sentences of method:

  • Raw AutoDock Vina 1.2 score — called a score, never a binding energy. State: rigid ligand (TORSDOF 0), rigid receptor, all transition metals mapped to the Zn atom type, seed, exhaustiveness.
  • Rank order within the panel, framed as triage for experimental testing rather than target identification.
  • A negative validation result. Prediction, measurement, disagreement and a traced mechanism is a stronger paper than an unexplained correlation.

Do not report, disclosure or not:

  • Any Ki derived from a docking score.
  • The composite score under thermodynamic language.
  • Mechanistic prose asserting inhibition class, metal coordination unsupported by the contact table, or mammalian selectivity.
  • Any LLM-generated citation that has not been opened and checked against the sentence it is attached to.
The Zn proxy is a known reviewer trigger for silver work, because Vina disregards atomic charge during sampling and Zn(II) is a borderline acid standing in for a soft, thiophilic Ag(I) centre. Expect it to be raised, and expect a request for redocking RMSD or a rescoring benchmark. Both are available above.
